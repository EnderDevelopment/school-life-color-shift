# Roblox Color Changer Script

This script changes the color of the player's character between black, white, and green every 0.5 seconds. All players in the game will see the color changes.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService.
3. Copy and paste the content of `ColorChanger.server.lua` into the script.
4. Save the script.

## Usage

The script will automatically run when a player joins the game. There is no additional setup required.
